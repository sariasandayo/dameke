# だめけー Web

Pokémon Champions対応の、非公式・非営利のファン制作ツールです。

## Webアプリ

[だめけー Webを開く](https://sariasandayo.github.io/dameke/)

## 主な機能

- ダメージ計算
- 計算履歴の保存・復元
- 攻撃・防御調整
- 素早さ調整
- 努力値最適化
- 補完ポケモン出力
- パーティタイプ評価
- ポケモン・パーティ管理
- ポケモン検索

## 保存データについて

保存内容は使用中のブラウザ内に保存されます。
